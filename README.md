# Skills For Mobile App Builders

Skills for developers who build mobile apps with AI agents, from the first idea to the finished screen.

## Install

```bash
npx skills@latest add turkmenugur/skills
```

## Why use it?

Agents ship the same app every time.

Ask an agent for a screen and you get a stack of rounded white cards with the same drop shadow, the system font, and no motion. Ask it to plan an app and you get a vague list of features with no stack, no structure, and nothing a coding agent can act on.

These skills fix both ends. One turns a raw idea into documents an agent can build from. The other forces every screen to have a feeling, a token system, real depth, and motion that responds to touch.

## Reference

- **[premium-mobile-ui](./skills/premium-mobile-ui/SKILL.md)** — Builds mobile screens that don't look generated. Names the feeling first, defines color, type, spacing and motion tokens, then writes layered UI with spring animations, haptics and micro-interactions. Works with React Native/Expo, Flutter, SwiftUI and Jetpack Compose, and covers engagement design without dark patterns.
- **[appblueprint](./skills/appblueprint/SKILL.md)** — Turns a raw app idea into five planning docs: `STACK.md`, `PLAN.md`, `DESIGN.md`, `FEATURES.md` and `ARCHITECTURE.md`. Every decision comes with its reason, so you can hand the docs straight to a coding agent.
