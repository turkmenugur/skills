# World-Class App Design Formula — Six-Stage Process

Source: Tim Gabe, "Our World Class App Design Formula." Read this when scoping a whole product or flow (not a single component) and you want a predictable path from raw idea to production-ready. Core principle: reduce risk at every stage so engineering moves fast afterward and users feel a real connection.

## Stage 1 — Onboarding (alignment)

Establish transparency, timelines, and clear channels from day one.

- **Single source of truth.** Don't scatter details across emails/chats. One organized space (e.g. Notion) for timelines, tasks, decisions, files, notes.
- **Day-one infrastructure.** Channels, shared folders, welcome checklists, and discovery docs immediately, so everyone is aligned.

## Stage 2 — Strategic Discovery

Balance speed and insight instead of jumping to pixels or over-researching.

- **Define constraints and metrics.** Run a focused discovery workshop to align on outcomes, guardrails, constraints, and success metrics.
- **Hands-on competitor analysis.** Actually download and use direct and indirect competitors; evaluate live experience, not from afar.
- **Align aesthetic taste.** Collect references and moodboards early to set explicit visual guardrails.

## Stage 3 — UX Architecture

Turn strategy into structure; solve core user problems before visual detail.

- **Prioritize key flows.** Not all screens are equal — invest in high-value journeys (onboarding) over utility screens (settings).
- **Wireflows and low-fidelity layouts.** Map journeys with wireflows; validate fast with low-fi wireframes before heavy design hours.
- **Emotional pinning.** Mark on specific wireframe screens *where* and *how* you want users to feel something — plan emotional moments deliberately.
- **Interactive prototyping.** Simulate complex flows, edge cases, and logic early.

## Stage 4 — UI Design

Elevate to world-class visual quality; small inconsistencies compound and destroy premium feel.

- **Start broad, go deep.** Explore multiple directions and concept screens before committing to a final high-fidelity system.
- **Reusable component library.** Systematize with explicit, component-by-component reusable patterns.
- **Airtight QA.** Stress-test every radius, opacity, asset, shade, and piece of microcopy. Misaligned radii and unintentional emphasis ruin perception and frustrate developers.

## Stage 5 — Emotional Integration

Most competitors stop at usability. To win, build emotional touchpoints that drive behavior and stickiness.

- **Lightweight interactive animations.** Use performant tools like Rive (used by Duolingo) for rich animation that doesn't slow the app.
- **Strategic, goal-driven micro-moments.** Don't animate for its own sake. Trigger emotion at high-leverage moments: checking a portfolio, entering secure data in fintech/web3 (to build trust), hitting a progression tier.

## Stage 6 — Cleanup & Delivery

Package everything for a seamless engineering handoff; skipping this turns small cracks into codebase problems.

- **Cover every state.** Design error states, empty screens, edge cases, accessibility details.
- **Clean specs.** Organize components, tidy master-file layers, outline accurate specs, package cleanly so engineering can execute fast.

## Summary

| Stage | Core action | Output |
| :-- | :-- | :-- |
| 1. Onboarding | Centralized portal | Single source of truth |
| 2. Discovery | Workshops + test competitors | Risk reduction, taste alignment |
| 3. UX Architecture | Wireflows + prototypes | Logic validated before visuals |
| 4. UI Design | Component library + QA | Pixel-perfection, premium feel |
| 5. Emotional Integration | Strategic micro-animations | Behavioral stickiness, delight |
| 6. Delivery | Edge cases + clean specs | Frictionless handoff |

> Core insight: reducing risk at each step keeps developer velocity high and ships a polished product users won't forget.
